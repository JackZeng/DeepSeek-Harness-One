# Roadmap

## 0.1 — Integrated local foundation

- Durable task event model.
- Official headless DSH process adapter.
- Offline demo runtime.
- Workspaces, artifacts, supervised memory, risk approval and proof.
- PWA control plane and local API.
- Curated extension registry.
- Guarded nightly ecosystem discovery and bounded evolution workflow.

## 0.2 — Native DSH event bridge

- Consume official session events rather than relying only on process output.
- Map DSH workflow runs, subagents, jobs and tool evidence to One task phases.
- Stream structured artifacts and approvals.
- Synchronize approved memory candidates with Mnemon spaces.
- Apply tier mode to an installed tier-router preset.

## 0.3 — Desktop distribution

- Signed macOS and Windows packages.
- Tray lifecycle, single instance and automatic local service recovery.
- Native directory picker.
- Profile and plugin lifecycle through stable desktop services.
- Secure mobile remote access.

## 0.4 — Team Mission Control

- Organizations, users, RBAC and workspace ACLs.
- Human and agent assignees.
- Approval inbox and policy ownership.
- AgentRQ, Slack, Feishu and enterprise messaging channels.
- Durable notification and offline delivery.

## 0.5 — Artifact Studio

- Editable document, web, dashboard, presentation, image and video surfaces.
- Open Design integration through a shared artifact contract.
- Design-system and brand-governed Studio workspace type.
- Review comments anchored to artifacts.

## 0.6 — Enterprise Data and Governance

- Mirage-backed organization data mounts.
- OpenGuardrails policy administration and detector selection.
- Private extension registry, signing and compatibility gates.
- Cost budgets, chargeback and model-route analytics.
- Backups, retention, legal hold and audit exports.

## Quality bar for every release

- A feature must fit the workspace/task/artifact/memory product model.
- The default path must not require users to learn Cordis or profile internals.
- Security and recovery behavior must be explicit.
- Claims of completion require reproducible evidence.
- New integrations must preserve upstream ownership and license boundaries.
